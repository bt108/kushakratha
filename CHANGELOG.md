# Change log

## Change Log Explanation

This change log documents all corrections and edits made to the draft translation. Each entry includes the original text, the revised text, and notes explaining the change. 

The "Type" field classifies the nature of each change:

- **Typographical**: Fixes obvious spelling or typing errors (e.g., duplicated letters, wrong capitalization if unintentional).  
- **Grammatical**: Fixes errors in sentence structure, agreement, or syntax without altering meaning.  
- **Lexical**: Replaces an incorrect word with the correct one based on context (e.g., "planet" → "plant").  

**Confidence** indicates the editor’s certainty about the correctness of the change: high, medium, or low.

All entries preserve the original text, and changes are documented transparently.

The following are silently corrected;

1. diacritics
2. Obvious mistakes e.g. Krrsna
3. Capitalization
4. Punctuation
5. quote marks ' "
6. Verses and translations taken from the BBT that got malformed.

All ambiguous cases are noted below
